## Git 备份规则

用户要求每次完成一轮修改并验证后进行 Git 提交。这一规则已写入根目录 `AGENTS.md`。

提交后运行 `scripts/backup-git.ps1`，在项目外的 `TransmissionLineDefectSystem-backups` 中保存并验证完整 Git bundle，包含原模型权重和历史版本；数据及本机配置仍使用独立备份。

美化版标签为 `ui-polished-v1.2.0`。若要回到 PDF 恢复后的原外观，可使用 `pdf-restored-v1.2.0-clean`。具体恢复方法见《Git备份与恢复说明.md》。
